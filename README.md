# 싸유즈 (SSAYUZ)

**디시인사이드 스타일 갤러리 게시판**과 **인스타그램 스타일 사진 피드**를 합친 SNS입니다.

## 기능

### ☰ 갤러리 (디시 스타일)
- 메인 갤러리 + 누구나 만드는 **마이너 갤러리 (ⓜ)**
- **유동**(닉네임 + 비밀번호, IP 앞자리 표시)과 **고닉**(로그인 계정, ✓ 배지)으로 글쓰기
- 말머리(일반/정보/질문/짤), 이미지 첨부(최대 10장)
- **추천 / 비추천** (1인 1회), 추천 5개 이상이면 **개념글** ★
- 전체글/개념글 탭, 제목+내용+글쓴이 검색, 페이지네이션
- 댓글 (유동/고닉), 비밀번호로 글/댓글 삭제
- 도배 방지 쿨다운

### ▦ 피드 (인스타 스타일)
- 사진 여러 장 업로드 → 스와이프 캐러셀
- **좋아요** (하트 버튼, 사진 **더블탭**), 댓글
- **팔로우** / 팔로워·팔로잉 목록, 팔로우한 사람들의 **피드**, 추천 계정
- **탐색** 그리드, `#해시태그` · `@멘션` 링크, 사람 검색
- 프로필 (게시물 그리드 / 갤러리에 쓴 글 탭), 프로필 사진·소개 편집

### 기타
- 반응형 (모바일 하단 탭바), 다크 모드 자동
- CSRF 보호, scrypt 비밀번호 해시, CSP, 업로드 이미지 매직바이트 검사, HTML 이스케이프

## 실행

Node.js **22.13 이상**이 필요합니다 (내장 `node:sqlite` 사용).

```bash
npm install
npm start          # http://localhost:3000
npm run dev        # 파일 변경 시 자동 재시작
```

데이터(SQLite DB와 업로드 이미지)는 `data/` 폴더에 저장됩니다.

### 환경 변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | DB·업로드 저장 위치 |
| `CONCEPT_THRESHOLD` | `5` | 개념글이 되는 추천 수 |
| `TRUST_PROXY` | (없음) | 리버스 프록시 뒤라면 `1` (유동 IP 표시용) |
| `COOKIE_SECURE` | (없음) | HTTPS로 서비스하면 `1` |
| `TZ` | `Asia/Seoul` | 시간대 |

## 구조

```
src/
  server.js          Express 앱 설정
  db.js              SQLite 스키마 + 기본 갤러리
  auth.js            세션, 비밀번호, CSRF
  upload.js          이미지 업로드 (multer + 검증)
  helpers.js         템플릿 헬퍼 (시간 표시, 해시태그 등)
  routes/auth.js     가입 / 로그인
  routes/gallery.js  갤러리 (/g/...)
  routes/social.js   홈, 피드, 탐색, 게시물, 프로필
views/               EJS 템플릿
public/              CSS, JS, 아이콘
```
