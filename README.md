# ssayuz

> 말은 **토크**로, 순간은 **스냅**으로.

🌐 **https://ssayuz.kro.kr** · 배포 방법은 [DEPLOY.md](DEPLOY.md)

ssayuz는 익명으로 가볍게 떠드는 **토크**와 사진으로 나를 남기는 **스냅**이 한곳에 있는 커뮤니티예요.

## 용어

| ssayuz | 뜻 |
| --- | --- |
| **토크 / 방** | 주제별 게시판. 공식 방과, 가입한 사람이 직접 여는 **USER 방** |
| **손님** | 가입하지 않고 닉네임 + 비밀번호로 쓰는 사람 (IP 앞자리 표시) |
| **단골** | 가입한 사람. 단골 배지가 붙어요 |
| **🔥 불지피기 / 🧊 찬물** | 글에 대한 반응. 🔥 − 🧊 = **화력** |
| **불타는 글** | 화력이 5 이상인 글 |
| **분류** | 잡담 · 정보 · 질문 · 짤 |
| **스냅** | 사진 게시물 (여러 장이면 넘겨 보는 앨범) |
| **좋아요 / 댓글** | 스냅에 남기는 반응 (사진 더블탭으로도 좋아요) |
| **팔로우 / 팔로워** | 내가 팔로우한 사람 / 나를 팔로우한 사람 |
| **프로필** | `/@아이디` |
| **스토리** | 24시간 뒤 사라지는 사진 |
| **DM** | 1:1 메시지 |

## 기능

**토크**
- 방 목록과 방 만들기 (대표 이모지 고르기)
- 손님/단골 글쓰기, 분류, 이미지 첨부 (최대 10장)
- 🔥/🧊 반응 (1인 1회), 화력 미터, 불타는 글 탭
- 말풍선 댓글 (글쓴이 댓글 강조), 방 안 검색
- 손님 글과 댓글은 비밀번호로 지우기, 도배 방지

**스냅**
- 폴라로이드 카드 피드: 내가 팔로우한 사람들의 스냅
- 좋아요, 댓글, `#태그`·`@멘션` 링크
- 둘러보기: 사진 벽(메이슨리), 태그 검색, 사람·방 검색
- 프로필: 스냅/토크 탭, 팔로워/팔로잉 목록, 프로필 편집 (사진, 소개)

**알림** 🔔
- 내 스냅에 좋아요·댓글, 내 토크에 댓글·🔥, 새 팔로워, @멘션이 오면 알려요
- 헤더에 안 읽은 개수 배지, 같은 사람의 반복 좋아요는 하나로 합침

**스토리** ⏳
- 사진 한 장 + 한 줄, **24시간 뒤 자동 삭제** (10분마다 정리, 사진 파일도 지움)
- 스냅 피드 위 스토리 줄 (안 본 스토리는 무지개 테두리), 프로필 사진에도 표시
- 자동 넘김 플레이어 (탭/←→ 이동, 스페이스 일시정지), 내 스토리는 본 사람 목록

**DM** ✉
- 받은 메시지함, 1:1 대화, 3초마다 새 메시지 확인, 읽음 표시
- Enter로 보내기 (Shift+Enter 줄바꿈), 헤더에 안 읽은 개수 배지

**관리자** 🛡
- 토크 글·댓글, 스냅·댓글 **숨기기 / 복구** (숨긴 항목은 관리자에게만 보임)
- **계정 차단** (사유 기록, 즉시 로그아웃, 로그인 화면에 사유 표시) / 해제
- **손님 IP 차단**: 손님 글·댓글 화면에서 바로 차단 (IP는 해시로만 저장)
- `/admin` 관리 페이지: 통계, 최근 글, 사용자, 숨긴 항목, IP 차단, 관리 기록

**기타**
- 디자인: 종이 배경, 굵은 테두리, 하드 섀도
- 글꼴: G마켓 산스 (Light, Medium, Bold), `public/fonts`에 포함
- 반응형 (모바일 플로팅 독), 다크 모드 자동
- CSRF 보호, scrypt 비밀번호 해시, CSP, 업로드 이미지 검사, HTML 이스케이프

## 실행

Node.js **22.13 이상**이 필요해요 (내장 `node:sqlite` 사용).

```bash
npm install
npm start          # http://localhost:3000
npm run dev        # 파일이 바뀌면 자동 재시작
```

데이터(SQLite DB, 업로드 사진)는 `data/` 폴더에 저장돼요.

### 관리자 지정

```bash
npm run make-admin -- alice          # 이미 가입한 alice를 관리자로
ADMIN_USERNAMES=alice,bob npm start  # 이 아이디들은 시작할 때 / 가입할 때 관리자가 돼요
```

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | DB·업로드 저장 위치 |
| `HOT_THRESHOLD` | `5` | 불타는 글이 되는 화력 |
| `TRUST_PROXY` | (없음) | 리버스 프록시 뒤라면 `1` (손님 IP 표시용) |
| `COOKIE_SECURE` | (없음) | HTTPS로 서비스하면 `1` |
| `SITE_URL` | `https://ssayuz.kro.kr` | 서비스 주소 (링크 미리보기, canonical) |
| `ADMIN_USERNAMES` | (없음) | 관리자로 지정할 아이디 (쉼표로 구분) |
| `TZ` | `Asia/Seoul` | 시간대 |

## 주소

| 경로 | 화면 |
| --- | --- |
| `/` | 홈 |
| `/talk`, `/talk/:방`, `/talk/:방/:글번호` | 토크 |
| `/snap`, `/snap/new`, `/snap/:번호` | 스냅 |
| `/explore` | 둘러보기 |
| `/@아이디`, `/@아이디/followers`, `/@아이디/following` | 프로필, 팔로워, 팔로잉 |
| `/stories/new`, `/stories/@아이디` | 스토리 올리기, 보기 |
| `/dm`, `/dm/@아이디` | 메시지함, 대화 |
| `/notifications` | 알림 |
| `/admin` | 관리 (관리자만) |

## 구조

```
src/
  server.js        Express 앱
  db.js            SQLite 스키마 + 기본 방
  auth.js          세션, 비밀번호, CSRF
  upload.js        이미지 업로드 + 검사
  helpers.js       템플릿 헬퍼
  notify.js        알림 만들기
  moderation.js    숨김 필터, IP 해시, 관리 기록
  routes/auth.js   가입 / 로그인
  routes/talk.js   토크 (/talk)
  routes/snap.js   홈, 스냅, 둘러보기, 프로필
  routes/stories.js       스토리 (+ 24시간 정리)
  routes/dm.js            DM
  routes/notifications.js 알림
  routes/admin.js         관리자
scripts/make-admin.js     관리자 지정
views/             EJS 템플릿
public/            CSS, JS, 글꼴, 아이콘
```

글꼴 G마켓 산스는 ㈜지마켓이 무료로 배포하는 글꼴이에요.
